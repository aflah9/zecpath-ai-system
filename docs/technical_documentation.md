# Zecpath AI Screening System

## System Overview

AI-based candidate screening platform that performs:

- Intent Detection
- Candidate Scoring
- Confidence Analysis
- Sentiment Analysis
- Behavioral Analysis
- Automated Report Generation

---

## Architecture

Candidate
    ↓
Speech/Text Input
    ↓
Intent Engine
    ↓
Scoring Engine
    ↓
Confidence Analysis
    ↓
Sentiment Analysis
    ↓
Behavior Report
    ↓
Final Screening Report

---

## Core Modules

Intent Engine
- Detects answer intent

Scoring Engine
- Generates candidate scores

Confidence Engine
- Detects hesitation

Sentiment Engine
- Evaluates sentiment

Behavior Report
- Creates behavioral indicators

Report Generator
- Creates recruiter-ready reports
