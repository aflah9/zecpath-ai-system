# Behavioral AI System Design – Zecpath

## Objective

Analyze candidate behavior using observable interview signals.

## Core Signals

1. Eye Movement & Gaze Stability
2. Head Movement
3. Facial Engagement
4. Attention Patterns

## System Pipeline

Video Feed
↓
Face Detection
↓
Eye Tracking
↓
Head Movement Analysis
↓
Engagement Detection
↓
Signal Aggregation
↓
Behavior Scoring
↓
Behavior Report

## Non-Invasive Principles

- No facial recognition
- No identity storage
- No emotion profiling
- Metadata only
- Candidate consent required
