1. Project Overview

This ATS system analyzes resumes and matches them with job descriptions using AI and NLP.
It provides scoring, ranking, and shortlisting of candidates.

2. Features
• Resume parsing (PDF/Text)
• Skill extraction using NLP
• Job description matching
• ATS scoring system
• Candidate ranking
• API support


3. Tech Stack
• Python
• FastAPI
• SpaCy (NLP)
• JSON-based data handling
