# HR Interview AI – Data Format Documentation

## Overview

This document defines the data structures used by the Zecpath HR Interview AI system. These formats are used for communication between AI modules, APIs, databases, and frontend applications.

---

# 1. Candidate Object

## Purpose

Stores candidate profile information used to start and track interviews.

## Structure

```json
{
  "candidate_id": "C101",
  "name": "John Doe"
}
```

## Field Description

| Field        | Type   | Description                 |
| ------------ | ------ | --------------------------- |
| candidate_id | String | Unique candidate identifier |
| name         | String | Candidate full name         |

---

# 2. Interview Session Object

## Purpose

Represents an active interview session.

## Structure

```json
{
  "session_id": "S123",
  "candidate_id": "C101",
  "job_id": "J501",
  "status": "active"
}
```

## Field Description

| Field        | Type   | Description                 |
| ------------ | ------ | --------------------------- |
| session_id   | String | Unique interview session ID |
| candidate_id | String | Candidate reference         |
| job_id       | String | Job opening reference       |
| status       | String | Current interview status    |

---

# 3. Question Object

## Purpose

Represents an interview question generated by the Question Engine.

## Structure

```json
{
  "question_id": "Q1",
  "question": "Tell me about yourself"
}
```

## Field Description

| Field       | Type   | Description                |
| ----------- | ------ | -------------------------- |
| question_id | String | Unique question identifier |
| question    | String | Interview question text    |

---

# 4. Answer Object

## Purpose

Stores processed candidate answers and extracted information.

## Structure

```json
{
  "question_id": "Q1",
  "answer_text": "I worked on backend systems",
  "intent": "experience",
  "skills": ["Python"],
  "confidence_score": 80,
  "communication_score": 75
}
```

## Field Description

| Field               | Type   | Description                    |
| ------------------- | ------ | ------------------------------ |
| question_id         | String | Question reference             |
| answer_text         | String | Candidate response             |
| intent              | String | Detected answer intent         |
| skills              | Array  | Extracted skills               |
| confidence_score    | Float  | Confidence evaluation score    |
| communication_score | Float  | Communication evaluation score |

# 10. Error Response Object

## Purpose

Standardized API error handling format.

## Structure

```json
{
  "error_code": "INVALID_INPUT",
  "message": "Missing candidate_id",
  "status": 400
}
```

## Field Description

| Field      | Type    | Description            |
| ---------- | ------- | ---------------------- |
| error_code | String  | Error identifier       |
| message    | String  | Human-readable message |
| status     | Integer | HTTP status code       |

---

# Summary

The HR Interview AI system uses standardized JSON-based data formats to ensure consistency between interview processing, scoring modules, API services, reporting components, and frontend integrations.
